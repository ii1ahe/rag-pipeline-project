# File guide

Use this guide to find the part of the project you want to read.

## Root files

| File | What it does |
| --- | --- |
| [.env.example](.env.example) | Example environment variables. Copy this to .env and fill in the values needed by the project. |
| [.gitignore](.gitignore) | Files and folders that Git should leave out of commits. |
| [FILES.md](FILES.md) | A short guide to the files in this repository. |
| [README.md](README.md) | Project overview and instructions for readers. |
| [main.py](main.py) | Loads documents, builds the vector store, retrieves three chunks per question, and runs two example questions. |
| [requirements.txt](requirements.txt) | Python packages needed to run the project. |
